# Software Testing Lab 5 OOP

This lab is for testing the SpellCaster Package in Java

### Setup

1. Clone down this repo
2. Install Maven dependicies found in the POM.xml
3. Run Maven Test
4. Observe test results, note due to the faults injected in the code, there will be errors from Maven test. These are not build errors rather test errors due to the package not behaving as intended.
